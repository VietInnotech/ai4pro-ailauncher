# Sidecar placeholder layout

This directory is reserved for planned **native** Tauri sidecars.

No real binaries are tracked here yet. The native files expected by the plan are:

- `llama-server-aarch64-apple-darwin`
- `llama-server-x86_64-apple-darwin`
- `llama-server-x86_64-pc-windows-msvc.exe`

`sherpa-onnx-vit` is **not** a native sidecar in this repo.
Treat it as a Python program packaged under `src-tauri/runtime/sherpa-onnx-vit/`.

Use the scripts in `scripts/` as manual-build scaffolding only.
